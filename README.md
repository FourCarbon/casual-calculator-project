# Simple Python Mini Calculator

A lightweight, terminal-based calculator built in Python that performs basic arithmetic operations with two user-provided numbers.

## 🚀 Features

| Feature | Description |
| :--- | :--- |
| **Arithmetic Operations** | Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`). |
| **Clean Input Parsing** | Uses space-separated single-line input for speed and ease of typing. |
| **Safety Error Handling** | Includes built-in protection to prevent crashes from division-by-zero errors. |
| **Invalid Operation Warnings** | Gracefully handles unsupported operator inputs with a friendly feedback message. |

## 🛠️ Tech Stack

| Component | Technology Used |
| :--- | :--- |
| **Language** | Python 3.x |
| **Paradigm** | Functional & Conditional Programming |

## 📦 Installation & Setup

Follow these quick steps to get the calculator running on your local machine:

1. Clone or download this repository to your system.
2. Make sure you have **Python 3** installed. You can check your version by running:
   ```bash
   python --version
   ```
3. Save your code into a file named `calculator.py`.

## 💻 Usage

To launch the calculator, open your terminal/command prompt, navigate to the directory containing your file, and run:

```bash
python calculator.py
```

Enter two values separated by a space (e.g., 1 3): 10 5
